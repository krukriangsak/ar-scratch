Scratch AR Adventure v5.7 — Bilingual Reading Bot

เพิ่มบอทช่วยอ่านตัวละครภาษาไทย “น้องช่วยอ่าน”
- โหมดไทย: อ่านภาษาไทยด้วยเสียงไทย และสลับเป็นเสียงอังกฤษอัตโนมัติเมื่อพบข้อความ/บล็อกภาษาอังกฤษ
- โหมด English: ใช้บอท Reading Buddy และบังคับเสียงอ่านเป็นภาษาอังกฤษ
- ปุ่มอ่านทั้งหน้า อ่านข้อความที่เลือก และหยุดเสียง
- เปลี่ยนภาษาไทย/English จากหน้าต่างบอท
- จดจำภาษาและสถานะเสียงใน localStorage
- แปลข้อความส่วนติดต่อหลักเป็นอังกฤษแบบทันที
- ใช้ Web Speech API และเลือกเสียงที่ตรงภาษาจากอุปกรณ์โดยอัตโนมัติ

ไฟล์ใหม่: js/reading-bot.js
แก้ไข: index.html, css/app.css
