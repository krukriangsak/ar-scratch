Scratch AR Adventure v5.2 Creator Studio

เพิ่ม:
1. Creator Studio ในหน้าแอดมิน
2. Visual UI Editor ปรับขนาด UI ความโค้ง ระยะห่าง ความกว้าง ตำแหน่งเครื่องมือลอย ซ่อนนาฬิกา/ประกาศ และ CSS เพิ่มเติม
3. Block Behavior Editor แก้ชื่อ หมวด ค่าตั้งต้น พฤติกรรม และ JavaScript ขั้นสูง
4. ตัวทดสอบบล็อกกับตัวละครและ Stage ก่อนเผยแพร่
5. ตรวจเตือนบล็อกที่ไม่มีพฤติกรรม
6. การเผยแพร่ UI และคลังบล็อกผ่าน Firestore system/uiLayout และ system/blockStudio
7. Scratch Block Lab ในหน้าผู้เล่นสำหรับเรียงคำสั่งและรันกับตัวละคร
8. บล็อกที่แก้จากแอดมินส่งผลต่อคลังใน Scratch Block Lab ทุกเครื่อง

หมายเหตุความปลอดภัย:
JavaScript ขั้นสูงมีไว้สำหรับผู้ดูแลที่เชื่อถือได้เท่านั้น เนื่องจากรันในเบราว์เซอร์ของผู้ใช้
