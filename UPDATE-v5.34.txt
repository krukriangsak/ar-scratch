Scratch AR Adventure v5.34 - Module Parse Fix

สาเหตุจริงที่หน้าเข้าสู่เกมโหลดไม่ครบ:
- ฟังก์ชันแปลง Google Drive URL ใน app-v3.js มี Regular Expression ที่ escape เครื่องหมาย / เกินมา
- ทำให้ Browser parse JavaScript Module ไม่สำเร็จ และ dynamic import รายงาน Failed to fetch dynamically imported module

แก้ไขแล้ว:
- แก้ regex เป็น /\/file\/d\/([^/]+)/ ที่ถูกต้อง
- สร้าง js/app-v34.js เป็นชื่อไฟล์ใหม่เพื่อเลี่ยง cache ของ app-v3.js รุ่นเสีย
- หน้าโหลด, Cute Login, กล้อง AR, Hand Drag, Admin Media URL และ Quick Edit ยังอยู่ครบ
- app-v3.js ถูกแก้ให้ถูกต้องเช่นกันเพื่อ compatibility
