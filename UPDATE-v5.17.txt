Scratch AR Adventure v5.17 — Playground ↔ Creator Studio Shared Blocks

- Scratch Playground now treats Creator Studio v5.16 published blockStudio data in Firestore as the primary block library.
- Bundled block-library.js is retained only as an offline fallback.
- Same-device Creator Studio edits sync to the open Playground immediately via sar-block-library-updated.
- Firestore onSnapshot keeps the Playground palette synchronized across devices.
- Only enabled + published blocks are shown to players.
- Existing blocks already placed in Code Area refresh their label, shape, opcode and custom JavaScript by stable Block ID while preserving learner-entered values.
- Added a visible Library source indicator in the Playground header.
- Creator Studio custom JavaScript continues to execute in Playground when useCustomCode is enabled.
