Scratch AR Adventure v5.6 – Editable JavaScript Blocks

- Shared English block library for Player Playground and Admin Creator Studio
- Every block contains an editable JavaScript template
- Added block shape, status, enabled and custom-code controls
- Added Duplicate, Load Template, Validate JS, Test, Save and Delete actions
- Published/enabled blocks sync through the existing shared block-library storage
- Playground can execute administrator JavaScript when Use Custom Code is enabled

Security note: JavaScript entered by an administrator runs in the browser. Only trusted administrators should edit or publish block JavaScript.
